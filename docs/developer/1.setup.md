# 1. Setup

Prepare the app, development tools and documentation environment.

## Prerequisites

Make, Bash, Git and uv on macOS, Linux or WSL2.
If uv is missing, run `make install-uv`; use `make update-uv` to update an existing installation.

## Install

```bash
git clone https://github.com/AmineDjeghri/personal-os-setup.git
cd personal-os-setup
make install-dev
make pre-commit-install
make check
```

This creates `.venv`, installs the development/docs tools and the Git hooks, and validates the checkout.
If dependency metadata changes, run `uv lock` before `make install-dev`; its `--locked` check requires an
up-to-date `uv.lock`. Checks do not install tools or hooks.

## Run

```bash
make run
```

This starts the TUI. To use the `personal-os-setup` launcher with this clone, run `./install_unix.sh` from it
(or `./install_windows.ps1` in administrator PowerShell). The installer updates the existing clone.

## Documentation site

```bash
make deploy-doc-local
```

## Optional environments and tools

| Command             | Use                                                   |
|---------------------|-------------------------------------------------------|
| `make install`      | Runtime dependencies only                             |
| `make install-prod` | Production dependencies only                          |
| `make update-uv`    | Update an existing uv installation                    |
| `make act`          | Run GitHub Actions locally (`make install-act` first) |

For publication, see [release credentials](5.release.md#credentials).

## Editor and agent rules

Select `.venv/bin/python`; mark `src` as Sources Root and `tests` as Test Sources Root.
Follow `.editorconfig` for indentation and line endings, including CRLF for PowerShell files.
Project skills live in `.claude/skills/`.
Agent rules live in `AGENTS.md`; `CLAUDE.md` links to it for Claude Code.
Edit `AGENTS.md` to update the shared instructions.

`make help` lists all targets. Next: [Conventions](3.conventions.md) and [Testing](4.testing.md).
