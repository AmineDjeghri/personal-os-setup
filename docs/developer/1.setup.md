# 1. Setup

Get a working development environment for the TUI app and its docs.

## Prerequisites

| Tool             | Version                          | Needed for                                       |
|------------------|----------------------------------|--------------------------------------------------|
| make, bash, git  | macOS, Linux or WSL2 defaults    | everything                                       |
| uv               | recent                           | everything; `make install-uv` installs it        |
| Python           | 3.14 or 3.15 (`requires-python`) | everything; uv downloads it                      |
| gh CLI           | any                              | optional: `make release*` from a laptop          |
| Docker           | any                              | optional: `make act` (run the workflows locally) |
| KVM/QEMU/libvirt | —                                | optional: `make vm-*` test VMs (Linux host)      |

## Install

```bash
git clone https://github.com/AmineDjeghri/personal-os-setup.git   # or your fork
cd personal-os-setup
make install-dev                                   # .venv with the app, dev and docs tools
make pre-commit-install                            # git hooks: checks on commit, commit message format
make test                                          # unit tests pass
make test-all                                      # every self-contained suite: unit, skills, built wheel
make docs-build                                    # strict documentation build (links, anchors)
make check                                         # the CI gate: lint + test-all + docs-build
make run                                           # start the TUI
```

`./install_unix.sh` (Linux, WSL2, macOS) or `./install_windows.ps1` (Windows, PowerShell as
administrator) run from inside a clone update that checkout in place instead of creating
`~/.personal-os-setup`: the `personal-os-setup` command then runs your editable checkout.

Use `make install-dev`, not `make install`: the latter installs no dev or docs tools.

## GitHub login (only to release)

```bash
gh auth login     # once; make release-version and make release-assets use this login
```

See [5. Release](5.release.md#credentials).

## Documentation site

```bash
make deploy-doc-local   # build and serve the site locally
```

New top-level folders must be added to the `exclude` glob of `properdocs.yml`, otherwise they are
published (`docs_dir: .`).

## IDE

- Interpreter: `.venv/bin/python`. Mark `src` as Sources Root and `tests` as Test Sources Root.
- `.editorconfig` sets indentation and line endings (tabs in `Makefile`/`*.mk`, CRLF for
  `*.ps1`/`*.bat`/`*.reg`).
- AI agents: rules in `AGENTS.md` (Claude Code reads it through `CLAUDE.md`), skills in
  `.claude/skills/`.

`make help` lists every target.
