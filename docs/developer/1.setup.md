# 1. Setup

Prepare the app, development tools and documentation environment.

## Prerequisites

Make, Bash, Git and uv on macOS, Linux or WSL2. uv provisions Python 3.14 or 3.15.
If uv is missing, run `make install-uv`; use `make update-uv` to update an existing installation.

## Install

```bash
git clone https://github.com/AmineDjeghri/personal-os-setup.git
cd personal-os-setup
make install-dev
make pre-commit-install
make check
make run
```

This creates `.venv`, installs Git hooks, validates the checkout and starts the TUI.
`make install` provides runtime dependencies only; checks do not install tools or hooks.

To use the `personal-os-setup` launcher with this clone, run `./install_unix.sh` from it
(or `./install_windows.ps1` in administrator PowerShell). The installer updates the existing clone.

## Documentation site

```bash
make deploy-doc-local
```

Preview the site locally; use `make docs-build` for a strict build without serving it.
`properdocs.yml` uses `docs_dir: .`: exclude new top-level output folders to keep them out of the site.

## IDE

- Select `.venv/bin/python`; mark `src` as Sources Root and `tests` as Test Sources Root.
- Use `.editorconfig` for indentation and line endings, including CRLF for PowerShell files.
- Agent rules: `AGENTS.md`; project skills: `.claude/skills/`.
